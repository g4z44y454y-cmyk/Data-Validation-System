# Data-Validation-System
A simple Java application developed using Apache NetBeans. The project demonstrates user input, login validation, conditional statements, and basic application design.

Technologies application :
-Java
-Apache NetBeans
-Java Swing

Features:
-User
-Login validation
-Conditional statements
-Success and unsuccessful messages 

Design:
The application uses a simple light grey background with black text for a clean and easy-to-use design.
